**仿Mooc在线学习平台 -（2025.03 - 2025.04）**

**项目简介：** 基于 Spring Cloud 微服务架构的在线学习平台，涵盖课程交易、学习管理和优惠券营销等核心业务。

**技术栈：** Spring Boot + Spring Cloud + MySQL + MyBatis-Plus + RabbitMQ + Redis + XXL-JOB

**个人职责与技术亮点：**

- **播放进度保存优化：** 针对视频学习进度高频更新导致数据库写压力过大的问题，设计**基于 Redis 缓存与延迟队列的优化方案**，将实时播放进度写入 Redis 缓存。使用 TTL + 死信队列实现延迟队列，通过延迟任务检测进度变更状态，异步将最终进度落盘到数据库，减少无效数据库更新。同时为避免消息阻塞，使用线程池异步消费延迟任务。
- **点赞服务解耦与缓存优化：** 抽离点赞为独立微服务，基于 MQ 解耦各业务的点赞数据同步。**使用 Lua 脚本 + ZSet** 设计针对用户重复点赞流量的滑动限流窗口。**基于 Redis 重构点赞模型**，使用 Set 存储用户点赞关系，ZSet 维护业务点赞计数，支持高效统计。使用 Pipeline 批量查询用户点赞状态，降低网络开销。**利用定时任务 + ZSet 的 ZPOPMIN 原子操作**实现点赞数据分批落盘，降低数据库压力并提高系统吞吐能力。
- **优惠券核心链路优化：** 针对多种使用规则不同的优惠券，使用**模板方法模式 + 策略模式**提高代码的扩展性和可复用性。基于 **Base32 与 JWT 算法思想**设计一套支持亿级兑换码、可脱离数据库高效校验的生成算法。在高并发情况下，**利用 Lua 脚本解决优惠券超发和限领问题**。针对优惠券组合串行计算耗时较长、响应慢的问题，基于**线程池**并行计算各组合优惠金额，使用 **CountDownLatch** 判断并行计算完成情况，按业务规则筛选最优抵扣方案。
